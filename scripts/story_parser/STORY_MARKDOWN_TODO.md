# 剧情 Markdown 解析待实现清单

样本页：`sources/static_pages/001_银辇啊_迅赴那黑色大地.html`

目标：把本地静态 HTML 转成可审查 Markdown，并在对白行中明确标注角色名。该 Markdown 仍是中间证据，不直接等同于最终角色文档。

## 样本页观察

- 有效剧情正文从 `h2#剧情内容` 后开始，前面的任务条件、系列任务、后续任务、剧情梗概不能混入对白主体。
- 普通对白多在 `ul > li` 中，格式常见为 `角色：台词`。
- 短信/聊天对白使用 `messageContent`、`SenderName`、`MessageLeft`、`MessageRight` 结构。
- 选项分支使用 `plotFrame`，其中 `plotOptions` 是玩家选项，后续多个 `content` 与选项按顺序对应。
- 额外对话和过场动画常放在 `sr-collapse-frame` 中，折叠状态不会影响 HTML 中的文本存在。
- `ruby` 会把正文注音/别名混在一起，需要转成更可读的 `正文（注释）` 形式。

## 资料页专项观察

样本页：`sources/static_pages/067_资料.html`，来源为 `遐蝶/资料`。

- 资料页没有 `剧情内容` 主区块，不能直接套用任务剧情页解析入口。
- 主要章节包括 `官方介绍`、`相关光锥故事`、`相关剧情&活动`、`相关物品`、`角色对话`、`专属LOGO`、`社媒专栏`、`人物考据`、`注释`。
- `官方介绍` 中有角色定位、官方问答和图片画廊；图片画廊可作为资源索引，但不应混入对白证据。
- `相关光锥故事` 是表格结构，包含光锥名和长段故事文本，适合转成“关联文本证据”。
- `相关剧情&活动` 是链接索引，其中包含主线、活动任务、交互事件和活动页，例如 `银河信号漫游`。
- `角色对话 / 大世界对话` 内部仍使用 `sr-collapse-frame` 和 `plotFrame`，可以复用现有分支对话解析逻辑，但入口必须限定在该章节范围内。
- 大世界对话按剧情进度折叠，例如 `大世界对话-3.0主线...后`、`大世界对话-3.1主线...后`、`大世界对话-3.2主线...后`，需要把进度标题、地点提示和分支对话一起保留。
- `相关物品`、`专属LOGO`、`社媒专栏`更像资源链接或低优先级补充，不适合进入角色性格证据正文。
- `人物考据` 是现实神话/命名解释，应单独标记为“考据”，不能和游戏内台词混为同等证据。
