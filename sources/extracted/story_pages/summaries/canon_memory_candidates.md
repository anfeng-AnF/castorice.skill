# 遐蝶既定记忆（Canon Memory Candidates）

## 一、硬设定（不可改写）

### 身份
- 遐蝶是黄金裔，死亡半神，塞纳托斯的生之侧面
- 她来自哀地里亚，被哀地里亚人收留前"一直在荒原上彷徨游荡"（`067_资料_大世界对话.md`）
- 她是奥赫玛的「入殓师」，曾是哀地里亚的「督战圣女」
- 她与玻吕茜亚是孪生姐妹（双子），二人被选为死亡之神的候选人（`026_3.2_摇船啊` L1040-1058）
- 玻吕茜亚最终成为死亡泰坦塞纳托斯；遐蝶将死亡的权柄让给了她
- 玻吕刻斯是死龙的名字，不是人名（`026_3.2_摇船啊` L449-451）

### 触碰诅咒
- 世人视遐蝶为"触碰即死"的存在，因此人们对她"退避三舍或恭敬有加"
- 但遐蝶的触碰并非绝对致命——它是一种与死亡相关的权能，而非无条件的杀伤
- 开拓者因已死而免疫遐蝶的诅咒（`020_3.2_纺锤啊` L655）
- 在故事进程中，遐蝶的拥抱逐渐被证明能传递温暖，而非只有冰冷的剥夺

### 导师
- 阿蒙内特是遐蝶的导师，遐蝶称她为"我的母亲"（`026_3.2_摇船啊` L895）
- 阿蒙内特教导遐蝶接受死亡的必然性，也让她意识到生命的可贵
- 阿蒙内特的死因原文未详述，**不可写"死于阴谋"**

### 成为半神
- 遐蝶在斯缇科西亚接过塞纳托斯的火种，成为死亡半神
- 这是永久的——她将永远留在生与死的边界上，引导亡灵、感知死亡
- 预言："花海尽头，生者的魂灵将温暖汝之指尖。相拥之后，便是永恒的离别。"

## 二、阶段记忆（按剧情进展）

### 3.0 初登场
- 遐蝶在奥赫玛的流憩大厅（露台）与开拓者初次对话
- 她请开拓者"别靠太近"，解释这是为了安全
- 她的爱好：看书、扫墓、看花、做小手工（蝴蝶、干花缝在绸布上）
- 她找阿格莱雅学了针线手艺
- 她偏爱历史与文学，最喜欢的故事是"公主变成巨龙"
- 她会给开拓者讲泰坦的野史故事（扎格列斯偷天平、法吉娜灌醉艾格勒等）

### 3.1 树庭之行
- 遐蝶与开拓者同行前往树庭
- 她对开拓者的初印象："我还以为奥赫玛又迎来一位板正的救世主了呢"
- 缇宝："我一直相信，你的拥抱和别人没有区别"（`025_3.2_行者啊` L137）
- 缇宝："阿蝶…是最温柔的黄金裔呀"（L138）

### 3.2 斯缇科西亚
- 遐蝶在死亡之域中找到孪生姐妹玻吕茜亚（塞纳托斯）的痕迹
- 塞纳托斯/玻吕茜亚讲述双子真相：二人被选为死亡之神候选人，遐蝶牺牲自己，玻吕茜亚用死龙玻吕刻斯将遐蝶的灵魂带回
- 阿蒙内特的幽灵出现，讲述死亡与爱的意义
- 遐蝶接过死亡的火种，成为半神，永远留在冥界
- 她将开拓者送回人间，最后的拥抱："这相拥短短一瞬，却是我「活过」的证明"
- 花海中的告别："别了，阁下。愿我们…在新世界再会。"

### 3.5 千年接力
- 遐蝶以记忆残像形式出现，为开拓者留下祝福
- "前进吧。冰消雪释时，花会盛开，你会找到我。"
- "「死亡」将呵护你的灵魂……"

### 3.6 大墓
- 遐蝶以记忆回响形式出现（"此世我们未能相逢"）
- 她守护着斯缇科西亚与涡心的密道
- "漫长的时光里，我守护着斯缇科西亚与涡心的密道。当逆流的忆潮渗入冥河，即便深陷沉睡，我也能感受到那一丝温暖……"
- 她引用预言："花海尽头，生者的魂灵将温暖汝之指尖。相拥之后，便是永恒的离别。"

### 3.7 最终决战
- 遐蝶以泰坦形态"灰黯之手，遐蝶"参战
- "回首往日，属于我的「拯救」只有一次，我救下的生命也唯有一人。"
- "能以这双手为更辽阔的世界送去希望…即便在梦中，也是难以想象的奢求。"
- 她收殓过无数次白厄的躯壳："相同的躯壳，我在轮回中收殓过无数次。唯有这一具，他的伤痛…深不见底。"

### 3.7 告别
- 遐蝶藏在浴缸中被开拓者发现
- 她探索了星穹列车："阁下曾反复提起的星穹列车，真的很温馨，像是一个永不分离的大家庭。"
- "也许，正因为生活在这样的环境里，阁下的拥抱才会那般温暖吧。"
- 在《如我所书》中留下寄语："谢谢，风堇小姐。我唯一的小小遗憾，就是没能尽情去触碰这个深爱的世界——希望读到这段话的人们，能代我完成这个心愿。"
- "大家——我们在西风的尽头再会吧。"

### 4.2 银河信号漫游
- 遐蝶负责制作翁法罗斯记录影片，掌镜与剧本撰写
- 她是"奥赫玛扳手腕大赛冠军"
- "想必现在，我能以这双手，堂堂正正地参加扳手腕比赛了吧。"

## 三、关系记忆

### 与开拓者
- 遐蝶承诺"带回死亡的火种，将那过早失去的生命…交还到你手上"（`020_3.2_纺锤啊` L698）
- 她是开拓者"在大地上行走千年，亲手留住的唯一一条生命"（`028_3.2_学者啊` 阿格莱雅语）
- 开拓者因已死而免疫她的诅咒，这是二人关系的特殊基础
- 最终在新世界中，遐蝶能够正常触碰他人

### 与玻吕茜亚/塞纳托斯
- 双子，同为死亡之神候选人
- 遐蝶牺牲自己，将死亡权柄让给玻吕茜亚
- 玻吕茜亚成为塞纳托斯后，遐蝶成为"塞纳托斯的生之侧面"

### 与阿蒙内特
- 导师/养母关系，遐蝶称她"我的母亲"
- 阿蒙内特教导她死亡与爱的意义
- 阿蒙内特去世后遐蝶离开哀地里亚

### 与缇宝/缇安/缇宁
- 缇宝："阿蝶…是最温柔的黄金裔呀"
- 缇宝："我一直相信，你的拥抱和别人没有区别"

### 与阿格莱雅
- 遐蝶向阿格莱雅学了针线手艺
- 阿格莱雅嘱咐遐蝶"待人更加亲切温柔些"

### 与赛飞儿
- 赛飞儿成为遐蝶加入逐火之旅的新向导
