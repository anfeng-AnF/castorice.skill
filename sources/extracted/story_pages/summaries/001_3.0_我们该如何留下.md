# 001 我们该如何留下

**版本：** 3.0

## 剧情概括

星穹列车抵达翁法罗斯上空，车厢被「纷争」泰坦尼卡多利的长矛贯穿坠落。开拓者和丹恒在废墟中醒来，遇到前来救援的白厄和缇宝。开拓者身受重伤但奇迹般恢复。众人前往圣城奥赫玛，途中白厄介绍了翁法罗斯的基本情况：十二位泰坦、黑潮威胁、以及黄金裔领导的「逐火之旅」。

开拓者被带入浴场接受治疗，初次见到阿格莱雅。阿格莱雅用金线试探开拓者的身份，确认其来自天外。众人了解到翁法罗斯被「天空」封闭，与外界隔绝。缇宝展示了通过「百界门」传送的能力。

白厄介绍了自己的过去——来自被黑潮毁灭的村庄哀丽秘榭，师从阿格莱雅学习战斗。丹恒和开拓者被安排在浴宫休息，开始了在翁法罗斯的旅程。

**关键角色：** 开拓者、丹恒、白厄、缇宝、阿格莱雅
