# 016 缇宝

**版本：** 3.1

## 剧情概括（缇宝梦境）

缇宝进入梦境，回到了童年时代。在梦中，她看到了母亲温柔的面庞——母亲给她讲故事，描述一艘大船上的船长、战士和学者。母亲用隐喻的方式预言了未来黄金裔的成员。

然而梦境逐渐扭曲，黑潮的阴影侵入。母亲的声音变得模糊，反复念叨着预言：「众人将与一人离别，惟其人将觐见奇迹。」缇宝意识到母亲已经不在了，而这段记忆正在被岁月侵蚀。

缇安在命运重渊遭遇盗火行者（黑袍剑士）的袭击。为了保护缇宝和缇宁，缇安耗尽了全部神力，将她们传送离开战场。缇安最后说了「明天见」，然后化作了一个普通的娃娃。

**关键角色：** 缇宝、缇安、缇宁、缇里西庇俄丝（母亲）、盗火行者
