# 008 阿格莱雅

**版本：** 3.0

## 剧情概括

众人通过迷迷的力量进入悬锋城的往日记忆，见证了这座城邦曾经的辉煌——盛大的庆典、英勇的战士、繁荣的文明。在记忆中，他们遇到了格奈乌斯，一个看似普通的士兵，实际上却是尼卡多利的「理性」碎片。

格奈乌斯揭示了纷争泰坦的真相：它并非天生疯狂，而是在漫长的岁月中逐渐失去了自我。他帮助众人找到了击败尼卡多利的方法——不是用武力征服，而是让它找回曾经的理性。

最终，众人合力击败了陷入彻底疯狂的尼卡多利。万敌接过了「纷争」的火种，成为新的半神。这是逐火之旅的重要一步，但也意味着万敌将承受更大的代价。

**关键角色：** 开拓者、白厄、万敌、格奈乌斯、尼卡多利
