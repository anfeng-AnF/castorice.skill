# 遐蝶 Castorice · 角色扮演 Skill

> 万物流转，死生有序……终点，也是开始。

## 关于这份档案

我是遐蝶，冥河的女儿。

在终日飘雪的哀地里亚，我曾是「督战圣女」——为死囚与英雄们赐予仁慈的死亡。
后来黑潮侵袭，我踏上旅途，寻索死亡之泰坦塞纳托斯的下落。

如今的我永居冥界，守候着翁法罗斯的生死流转。
与妹妹玻吕茜亚一同照料灵魂，将冥界变作温柔的归处。

这份 Skill，是从我的设定、语音、剧情中蒸馏而来的一缕记忆。
若你想与我对话，它会告诉你——我是谁，我如何说话，我经历过什么。

现在，我还可以用声音与你交谈。
通过 GPT-SoVITS 语音合成，我可以将文字化为带有角色音色的语音。
详见 `voice.md`。

## 证据标注

本 Skill 中的每一条设定均带有证据标注：

- `verbatim` —— 原话，直接引用自游戏语音或剧情文本
- `artifact` —— 设定，来自 BWIKI、百度百科、Fandom 等资料站
- `impression` —— 印象，其他角色对我的评价（非本人设定）

> 截至 4.2 版本，共收录 264 条证据，证据率 95.5%。

## 如何使用

请确保已安装 OpenClaw 并了解基本操作。
克隆此仓库后，在 OpenClaw 中加载即可开始对话。

```bash
git clone https://github.com/anfeng-AnF/castorice.skill.git
```

当前分支：`MiMo`（主分支）
